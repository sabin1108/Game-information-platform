- E2E: 공개 홈, 검색 제출/초기화, 비밀번호 토글, 본문 바로가기, 404 복귀, 320/768/1440px 가로 넘침, 모바일 활성 탭 및 웹뷰 스토어 bridge를 검증했습니다.
- 타입 검사, ESLint, Next 프로덕션 빌드 및 git diff --check를 실행했습니다.
- 데스크톱 1440px와 모바일 393px에서 홈·할인·검색·로그인을 캡처했습니다. 캡처는 로컬 .omx/artifacts/frontend/에 있습니다.
- 이전 고정 데이터 대신 실제 반환된 24개 홈 카드가 렌더링되는 것을 확인했습니다. 브라우저 초기 화면 검사에서 JavaScript 오류 0개, 가로 넘침 0px였습니다.

## 선택 이유와 범위

- 기존 CSS와 Lucide, 폼, 카드, 피드를 확장했습니다. 새 패키지를 추가하지 않았습니다.
- 자동 로드에 수동 더 보기를 함께 제공해 키보드 사용과 IntersectionObserver가 없는 환경을 지원합니다.
- 목록 개수를 전체 할인 수처럼 표현하지 않고 현재 확인한 게임 수로 안내합니다.
- 기존 실험 노출·카드 클릭 분석과 웹뷰 bridge를 유지했습니다.
- 가격·표지 자체가 공급되지 않는 경우에는 예시/대체 상태를 표시합니다. 모든 게임의 최신 가격이나 원본 표지 확보를 보장하지 않습니다.
- 실제 Supabase 계정 생성·삭제를 수반하는 인증/관심 목록 통합 테스트와 OAuth 공급자 설정, 외부 배포는 이번 검증 범위에 포함하지 않았습니다. 입력·목표 폼·추가 폼·API 단위 테스트 및 공개 화면/웹뷰 E2E를 검증했습니다.
- 이력서 PDF와 다른 프로젝트에 대한 피드백은 이 저장소 범위에 포함되지 않습니다.


## 원본 게임 표지 복구

- 누락 원인: 확인 시 홈 24개 중 17개는 서버 응답의 imageUrl과 steamAppId가 비어 있었습니다. 이미지 다운로드 실패가 아니라 표지 조회 경로 누락이었습니다.
- 게임의 ITAD UUID로 [공식 Game Info API](https://docs.isthereanydeal.com/#tag/Game/operation/games-info-v2)를 조회합니다. 응답 ID가 요청 ID와 같을 때만 표지를 사용합니다.
- 제공된 배너/박스아트를 우선하고, 표지 자산이 없는 경우 같은 공식 응답의 Steam appid로 해당 게임의 Steam header를 사용합니다. Shadow Warrior에서 이 경로를 확인했습니다.
- 홈·할인·검색의 표시 대상 중 이미지가 없는 게임만 보충합니다. 가격/제목/정렬 순서는 바꾸지 않습니다.
- 서버 프로세스별 24시간 메모리 캐시(최대 1,000건), 동일 ID 동시 요청 병합, 조회당 최대 4개 병렬 처리와 시간 예산을 적용했습니다. 실패 결과는 짧게 캐시해 재시도를 허용하고, 이전에 확보한 URL은 유지합니다.
- 표지 코드: src/lib/game-artwork.ts, src/lib/itad.ts, src/lib/itad-normalizers.ts. 피드 연결: src/lib/game-feeds.ts, src/lib/search.ts.
- 검증: 정확한 ID 매칭, 가격 보존, 캐시와 동시 요청 병합, 실패 격리/재시도, 기존 이미지 보존, Steam 원본 보충, 표시 대상만 보강하는 통합 회귀 테스트.

최종 원본 표지 검증: 로컬 프로덕션 홈 24개 게임 모두 이미지 로드 완료(naturalWidth > 0), 누락 0개. 기존 누락 17개 복구. 전체 27개 테스트 파일 / 77개 테스트, 타입 검사·린트·빌드 통과. 실제 로드 목록은 .omx/artifacts/frontend/artwork-verification.json, 화면은 real-covers-desktop.jpg / real-covers-mobile.jpg에 저장했습니다.

## 검색·필터 구조 재설계

검색창을 하나로 통합하고 제목·태그·스토어·원화 예산·할인 여부·정렬을 공통 URL 모델로 연결했습니다. 제목 없는 태그 선택은 실제 할인 API로, 제목 검색의 태그는 정확한 게임 UUID의 메타데이터로 처리합니다. 서버 Suspense로 검색 조건을 먼저 전송하고, 필터 변경 시 제목 후보 캐시 및 진행 중 요청을 공유합니다. 구현 근거·로컬 측정값·이력서 문장·한계는 [검색 성능 사례](frontend-search-case-study.md)에 기록했습니다.
